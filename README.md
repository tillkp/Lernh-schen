# Lernhäschen 🐰

Android-Vokabeltrainer für Französisch und Latein (LG Velvet, Android 12).

Funktionen: Vokabelkarten, lokale Lernstände, Häschen-Belohnungen, tägliche 15-Uhr-Erinnerung und Fotoimport mit Texterkennung.

Der erste Prototyp liegt noch als ZIP-Datei in der ChatGPT-Unterhaltung vor. Android-Build über GitHub Actions wird eingerichtet.
